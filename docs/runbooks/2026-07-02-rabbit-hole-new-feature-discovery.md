# Rabbit Hole — New Feature Discovery (2026-07-02)

Discovery/spec work only — nothing here is implemented. Produced by studying both repos:
backend/content machine `mindpattern-v3` and website `mindpattern-rabbit-hole`
(branch `feature/rabbit-hole-public-intelligence-site`).

**Dirty-state record at start of this work:** both repos clean (`mindpattern-v3` on
`main`, `mindpattern-rabbit-hole` on the feature branch, no modified/untracked files).

---

## 1. The current system, briefly

**v3 backend (Python, Mac launchd + Fly.io).** A deterministic 12-phase nightly pipeline
(`INIT → TREND_SCAN → RESEARCH → SYNTHESIS → DELIVER → SITE_CONTENT → LEARN → SOCIAL →
ENGAGEMENT → IDENTITY → MIRROR → SYNC`) runs 13 research agents, writes to SQLite
(`memory.db`), and syncs to Fly, where a FastAPI app serves the public read API.

Corpus today (live counts from `data/ramsay/memory.db` + `reports/ramsay/`):

- **15,513 findings** (15,392 embedded — `bge-small-en-v1.5`, 384-dim, brute-force cosine)
- **2,002 source domains** with reputation counters (`hit_count`, `high_value_count`)
- **4,201 entity edges** — but *all* typed `reported_on` (a bipartite mention graph)
- A fully designed **bi-temporal knowledge graph** (`kg/schema.py`: 8 entity types,
  15 typed predicates, `valid_at`/`invalid_at`, fact/opinion/prediction tagging,
  Louvain communities) that is **schema-only, not populated**. The API already reads
  it defensively — populating it lights up richer features with near-zero API work.
- **155 daily briefings**, ~3,324 public stories (only ~90 with a written "take";
  backfill ongoing), **31 entity/source dossiers**, **1 narrative-arc artifact**,
  298 skills, 97 patterns + 223 validated patterns, 234 cross-pipeline signals,
  666 trend-history rows.
- Operator-only capabilities: **follow-up research** (Slack question → 4 parallel
  researchers → markdown answer), **audio briefings** (builder complete, 0 artifacts),
  **video script packages**, **social angle lab**.

**Rabbit Hole website (Next.js 16 on Vercel).** No content in the repo — every page
fetches the Fly API at request time (60s ISR). Live surfaces: the Wire feed (Trending /
Most Read / Latest / Topics), story pages with takes + evidence-backed related paths,
entity pages with compiled dossiers + typed-edge lists, source pages, finding
rabbit-hole drill-down, narrative-arc pages, briefings archive with audio player,
unified `/search` (stories/findings/entities/sources), first-party privacy-safe
analytics, JSON-LD everywhere, AI-crawler-friendly robots, full-graph sitemap
(~4,277 URLs). Newsletter = "The Ramsay Research Report" via Resend.

**Absent today** (mix of spec'd-but-unbuilt and never-proposed): OG images, RSS,
`llms.txt`/OKF, visual graph view, standalone dossier/connections/trend pages,
personalization, any live AI answering (the Ask panel was added and removed on
2026-07-02 — search is retrieval-only by decision), analytics dashboard, attribution.

## 2. What Rabbit Hole should become

A **living public intelligence graph** — the place where humans *and* their agents
consume MindPattern's research as a queryable, citable, watchable knowledge product,
not a feed of posts. Three shifts:

1. **From archive to instrument.** Visitors don't just read what the machine wrote;
   they watch topics move, follow storylines, compare entities, check predictions,
   and commission research. Return visits are driven by *deltas*, not new posts.
2. **From pages to a graph with provenance.** Every claim traces to findings, sources,
   and time. Trust is a feature: source track records, disputed claims, citation
   formats, and a transparent "machine room."
3. **From human-only to agent-native.** Agents get first-class read paths (markdown
   twins, feeds, vector search, graph queries, changelogs, webhooks) so Rabbit Hole
   becomes infrastructure other AI systems cite and build on — the AEO strategy made
   concrete.

## 3. Existing broken/legacy behavior — explicitly NOT in this list

To keep the table honestly "new," these known issues are acknowledged here and
excluded: legacy `/blog` duplicating `/briefings`; `/explore` marked for retirement;
orphaned chat/MCP client code (`src/components/chat/*`, `src/lib/mcp-tools.ts`,
`src/lib/system-prompt.ts`); three coexisting design languages (Signal vs Wire Room vs
`PRODUCT.md` console) with `CLAUDE.md` describing the outdated one; the degenerate
all-`reported_on` entity graph; feature-branch work not yet deployed; unused AI SDK
dependencies. Cleaning any of these is a fix, not a feature.

last column says how it goes materially beyond the sketch.
