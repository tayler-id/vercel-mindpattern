## A. What the data actually is (verified against the live backend)

- 3,324 published stories, 15,513 findings (13 agents, `agent` 100% present),
  132 briefings (median 4,397 words), 2,002 sources, ~25 stories/day.

  bucket wrongly stored as a section.

- Titles: median 73 / max 168 chars (display type must handle 3 lines).
  Summaries: hard 280-char cap (uniform 2–3 line dek). 50/page API limit.

## C. The design decisions (what "color matters" means here)

1. **Taxonomy registry** (`src/lib/topics.ts`): the 11 real sections, each
   with: id, display label (AGENTS, RESEARCH, TOOLS, MARKETS, SECURITY,
   INFRA, MODELS, VIBE CODING, OSS, POLICY, SKILLS), fixed hue, and keyword
   signature. `top-5-stories-today` maps to a rank flag, never a topic.
2. **Category for every story**: use `section_id` when present (92% of
   archive); otherwise classify from `topic_terms` keywords (100% present)
   via the registry signatures. Flag the pipeline regression in the v3 repo
   as the permanent fix (backend assigns sections again).
3. **Category palette**: 8 AA-checked hues covering 11 sections (related
   sections share a family: TOOLS/VIBE/OSS, POLICY/SECURITY). Palette
   proposed with swatches before implementation.
4. **Color continuity rule**: a story's category hue is identical at every
   touchpoint — wire kicker + numeral + flood, rail marker, graph node,
   and INSIDE the story page (progress rail, link underlines, take block,
   related-section rule). Hover color and destination always agree.
5. **Pills everywhere or nowhere**: with category derived for all stories,
   every row gets its topic pill. One size, one geometry.
6. **Composition hierarchy**: exactly one 3px ink rule per page section
   head; hairlines only between list items; one content width per page zone;
   no rules doing decoration.
7. **Truth in labels**: rail = "THE WIRE — LATEST 300 OF 3,324" (or full
   lazy-load); "Most read" hidden until analytics are real; arcs unlinked
   until data exists; /blog redirected to /briefings.
8. **Connections made visible**: related_paths' 8 connector types get a
   designed vocabulary (label + hue-neutral icon), shown on story pages and
   as "connected stories" counts on wire rows where cheap.
9. **De-shadcn pass**: custom select trigger (chevron inset 16px, pill
   geometry from the system), no native control leaks anywhere.
