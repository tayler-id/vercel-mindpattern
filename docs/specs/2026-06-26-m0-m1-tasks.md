## M0 — Foundation: Signal UX on real data

### T1 — Signal design system in the app
**Desc:** Port Signal tokens into `globals.css` (`@theme inline`): Inter + JetBrains Mono + Newsreader, cobalt accent, light only, no-left-border, app-feel base (safe-area, tap, momentum). 
**Acceptance:** tokens available app-wide; a sample page renders in Signal; reduced-motion respected.
**Verify:** `pnpm build`; browser: sample page matches prototype look.
**Deps:** T0. **Files:** `globals.css`, root `layout.tsx`. **Size:** S–M.

### T2 — Data layer over the existing proxy
**Desc:** Typed client for the live backend (findings, reports, sources) via the existing `/api/proxy` + `src/lib/api.ts`; confirm shapes in `src/lib/types.ts`.
**Acceptance:** `getFindings/getReports/getReport/getSources` return real data, typed.
**Verify:** `pnpm test` (unit on the client); a route logs real findings count (~14.9k reachable).
**Deps:** T0. **Files:** `src/lib/api.ts`, `src/lib/types.ts`. **Size:** S.

### T3 — Wire (front page) on real findings
**Desc:** Render real findings as Signal rows (rank · kicker/category · headline · source favicons + "N sources" · leader-avatar slot). *(Interim: takes/clusters arrive in M4 — see Sequencing note.)*
**Acceptance:** Wire lists real findings; favicons + source counts render; mobile app-feel.
**Verify:** browser on `pnpm dev`: Wire shows live findings, scrolls, responsive.
**Deps:** T1, T2. **Files:** `src/app/(wire)/page.tsx`, `src/components/wire/*`. **Size:** M.

### T4 — Finding reading page + video player
**Desc:** `/f/[id]` renders a real finding + sources; if a source is a video, embed a **click-to-load** player (facade, no heavy dep).
**Acceptance:** finding page renders real content + sources; a YouTube-source finding plays on-site.
**Verify:** browser: open a known video finding → player loads on click.
**Deps:** T1, T2. **Files:** `src/app/f/[id]/page.tsx`, `src/components/video/*`. **Size:** M.

### T5 — Briefings section
**Desc:** Briefings list (real `/reports`) + one long-form briefing rendered (streamdown, serif), archive nav.
**Acceptance:** list shows real dates/titles; a briefing renders formatted long-form.
**Verify:** browser: `/briefings` list + a dated briefing render real content.
**Deps:** T1, T2. **Files:** `src/app/(briefings)/*`, `src/components/briefing/*`. **Size:** M.

### T6 — One-click subscribe
**Desc:** Frictionless newsletter signup (Resend) — single field + button everywhere + sticky CTA; forms-guide a11y (autofill, ≥16px, validate-after-interaction, accessible errors).
**Acceptance:** real subscribe via Resend; accessible; one-tap where autofill allows.
**Verify:** browser: submit → success; screen-reader error path; `pnpm lint` clean.
**Deps:** T1. **Files:** `src/components/subscribe/*`, `src/app/api/subscribe/route.ts`. **Size:** S–M.

### T7 — App shell + nav + base a11y
**Desc:** Header + **bottom tab bar** (mobile) + skip link + `#main` landmark + JSON-LD; safe-area insets.
**Acceptance:** nav works across Wire/Briefings; skip link focuses main; tab bar on mobile.

**Deps:** T1. **Files:** `src/app/layout.tsx`, `src/components/shell/*`. **Size:** M.

## M1 — Findings as spine + semantic rabbit hole

### T8 — Finding + feed API (v3)
**Desc:** v3 endpoints `/api/finding/{id}` and `/api/feed` (paged findings, recency for now). Confirm embeddings are queryable server-side.
**Acceptance:** endpoints return real findings JSON; embeddings accessible to the related job.
**Verify:** `curl` returns valid JSON; pytest on shape.
**Deps:** T0. **Files:** v3 `dashboard/routes/*`. **Size:** S–M. **Repo:** v3.

### T9 — Semantic related API (v3)
**Desc:** `/api/related/{id}?mode=semantic` — top-K cosine neighbors over the existing ~14.8k embeddings (reuse `memory/embeddings.py`).
**Acceptance:** returns ranked related findings with scores; excludes self; <300ms typical.
**Verify:** pytest: known finding → sensible neighbors; manual spot-check relevance.
**Deps:** T8. **Files:** v3 `memory/*`, `dashboard/routes/*`. **Size:** M. **Repo:** v3.

### T10 — Rabbit-hole UI on real related
**Desc:** Wire the finding page's "more like this" + drill-down columns/collapsing trail to `/api/related?mode=semantic`. View Transitions for the drill (Chrome-first + fallback).
**Acceptance:** click a finding → real related; follow it → new column; never empty.
**Verify:** browser: traverse 4+ levels on real data; reduced-motion ok.
**Deps:** T3, T4, T9. **Files:** `src/components/story/*`, `src/lib/api.ts`. **Size:** M.

### T11 — Events ingest + trending stub
**Desc:** `/api/event` ingest (anon_id, type, target, ref_source/campaign) + a simple trending sort feeding the Wire (full analytics/recsys = M2).
**Acceptance:** events persist; Wire can sort by a basic trending score.
**Verify:** fire test events → appear; Wire order changes.
**Deps:** T8. **Files:** v3 `events` table + route; `src/lib/events.ts`. **Size:** M. **Repo:** v3+FE.

### ✅ Checkpoint — M1
- [ ] Click any finding → **real semantic related**; rabbit hole traverses live data, never dead-ends
- [ ] Events recording; Wire reflects a basic trending sort
- [ ] build/lint/test green both repos; browser-verified
